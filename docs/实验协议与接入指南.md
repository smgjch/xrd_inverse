# XRD 晶格反演实验协议与 baseline 接入指南

版本：`xrdbench-0.1.0`。日期：2026-11-23。适用对象：分别负责物理搜索、CNN/ConvNeXt、MDN、NSF、cVAE 及 cVAE+Physics 的合作者。

本文给出可执行的首版共同协议。`smoke` 发布用于接口验证；`pilot` 用于开发、预算估算和可辨识性检查；`main` 才用于论文主表。完整大规模数据尚需协调者生成并发布，不能把 smoke 成绩当成 baseline 性能。协议数值如需改变，必须在所有方法正式测试前统一升版、重新发布，不能某一方法单独更改。

## 1. 研究问题与比较边界

给定已知原型、化学组成、分数坐标、波长和一张部分观测的粉末 XRD，估计连续晶格参数 θ。不预测元素、空间群、原子坐标或完整未知结构；不声称模拟结构都能稳定合成；不声称本实验验证了真实实验谱泛化。

核心假设：在有限观测、有噪声或模型失配时，物理约束是否改善**摊销后验估计**的精度、校准、可用候选或效率。多解、生成性优势和物理项优势均需实验验证，不预设 cVAE 优于 NSF、MDN 或充分收敛的数值物理后验。

主表至少包括：Prior mean / prior sampler；Physics MAP 与经过收敛检查的数值后验；强 1D-CNN/ConvNeXt；CNN+Physics；MDN；NSF；vanilla cVAE；cVAE+Physics。不同输出类型有不同可比较的指标，不能用 oracle best-of-K 直接取代部署点预测精度。

## 2. 固定原型与参数约定

| 任务 ID | 用途 | 输出顺序、单位 | 参考晶格 | 固定结构 |
| --- | --- | --- | --- | --- |
| `si` | 管道正确性检查 | `[a]`，Å | a=5.431 | Fd-3m (227)，常规立方胞，8 Si |
| `rutile` | 主任务 | `[a,c]`，Å | a=4.5937，c=2.9587 | P4₂/mnm (136)，2 Ti+4 O，O 内坐标 u=0.305 |
| `zno` | 第二原型复核 | `[a,c]`，Å | a=3.2495，c=5.2069 | P6₃mc (186)，2 Zn+2 O，O 内坐标 u=0.3825，γ=120° |

每个长度独立服从 `Uniform(0.95×reference, 1.05×reference)`。内部坐标、占位、晶胞约定固定；不能重新约化胞、交换 a/c，或把六方胞当正交胞。每原型分别训练，ZnO 结果不称为跨原型零样本泛化。

v0.1 的原型由 `physics.structure()` 的标准空间群与显式坐标构造，并导出 `prototype.cif`。它们是**理想化原型**，不是下载的实验 CIF；这项来源信息写入 manifest。后续若换成某数据库的实验 CIF，需记录数据库 ID/许可证/文件哈希并发布新数据版本，不能静默替换。LiFePO₄ 三参数、跨晶系、参数空间区块留出和真实谱目前不属于已实现的 v0.1。

## 3. 两条信息条件不同的赛道

### 3.1 `calibrated`：仪器与尺度参数已知

每个观测提供以下五个 nuisance 参数，顺序固定：

`[FWHM_deg, zero_shift_deg, scale, background_density, background_slope]`。

ID 条件中为 `[0.15, 0, 1, 0.01, 0]`。`broad_ood` 的实际 FWHM 也提供给所有方法。物理方法可以直接使用这些量；神经方法可以把它们作为额外特征。比较的是晶格后验及对训练条件变化的适应性。

### 3.2 `blind`：nuisance 未知

所有方法只知道下表中的训练先验，不能读取每张谱的 nuisance 真值：

| 参数 | 分布 |
| --- | --- |
| FWHM | Uniform(0.10,0.30) ° |
| 零位偏移 | Uniform(-0.04,0.04) ° |
| 强度尺度 s | LogUniform(0.7,1.3) |
| 背景密度 b₀ | Uniform(0.003,0.02) /° |
| 背景斜率 b₁ | Uniform(-0.4,0.4) |

暴露的 `nuisance` 数组全为 NaN，`nuisance_known=False`。网络可以把未知值填零，但必须保留“未知”标志。不能把填零值当成物理参数调用似然。

物理 MAP 可联合优化 nuisance；数值后验应按先验积分/采样边缘化 nuisance。前者得到的 profile likelihood 不等于后者的边缘后验。当前共享物理候选评分器**仅支持 calibrated**；在 blind 上请求物理评分会明确报错，不会偷偷使用真值。blind 的统一边缘似然实现属于后续必须补齐的工作，在补齐前只发布原始预测指标和清楚声明的各方法独立处理结果。

两条赛道分别训练、分别排名，不混成一张平均成绩表。

## 4. 共同正向模型与强度单位

固定 Cu Kα₁ 单色波长 `λ=1.5406 Å`，并非 Kα 双线。观测轴为 `2θ∈[10°,90°]`、4096 个等距中心，步长 `Δ=80/4095°`，含两端点。

`pymatgen.XRDCalculator(symprec=0)` 计算 5–95° 的棒状峰，`scaled=True` 将最强积分反射强度设为 100。采用该固定峰计算范围以覆盖测量范围两端的展宽尾部；范围外反射尾部被截断，是共同模拟器的约定。没有额外的 Debye–Waller、Kα₂、混相或微应变模型。

对观测 bin i：

```text
μᵢ = E · Δ · { s Σⱼ (Iⱼ/100) k(2θᵢ - pⱼ(θ) - δ; w)
                + b₀ [1 + b₁(2θᵢ-50)/40] }
yᵢ ~ Poisson(μᵢ)
```

`k` 是积分为 1 的 Gaussian 密度，FWHM=w；OOD pseudo-Voigt 为 Gaussian/Lorentzian 各 0.5。代码以中心值×Δ近似 bin 积分；最小 ID FWHM=0.10°，约 5.1 个 bin。需要更细网格或精确 bin 积分时必须升版，不能只给一个方法换前向模型。

`E` 是已知计数曝光尺度：在无边界截断、s=1 时，积分强度为 1 的孤立反射约有 E 个总计数。**它不是每个 bin 的峰高，也不是 SNR 或全谱总计数**。所有方法拿到 E。训练和推理不得使用真实完整干净谱的最大值做归一化；提供的 `encode()` 仅用观测 counts、已知 E 和 mask。

固定缺测 bin 的 counts=0，但必须同时输入 `mask=False`。似然只在 mask=True 的 bin 求和；不能把补零当成真实零计数。`physics.poisson_nll()` 省略与参数无关的 log(y!)，可用于同一观测下排序；不是完整归一化 log evidence。

## 5. 11 个固定测试条件

| condition | 类型 | E | 观测/扰动 |
| --- | --- | --- | --- |
| `full_high` | ID | 100000 | 全谱；仍有 Poisson 噪声，不能叫完全无噪声 |
| `full_standard` | ID | 10000 | 全谱 |
| `full_low` | ID | 1000 | 全谱、低计数 |
| `block30` | ID | 10000 | 连续缺测 round(0.30×4096) 个 bin |
| `block50` | ID | 10000 | 连续缺测 round(0.50×4096) 个 bin |
| `window25_45` | ID | 10000 | 仅观测 25–45° |
| `broad_ood` | OOD | 10000 | 全谱，FWHM∼Uniform(0.4,0.7)° |
| `voigt_ood` | OOD | 10000 | 全谱，峰形改为 50% pseudo-Voigt |
| `drop30_ood` | OOD | 10000 | 每个棒状峰独立以 0.3 概率消失，mask 仍全 True |
| `window26_30_stress` | stress | 10000 | 仅观测 26–30° |
| `no_signal_stress` | stress | 10000 | 全部 bin 未观测，正确后验为参数先验 |

连续缺测块的起点均匀采样且与 θ、真实峰位独立。窗口是固定绝对角度，不跟随真实峰移动。未知峰消失属于“测到了但反射没出现”，不提供按真值构造的缺峰标签。

训练条件从六个 ID 条件等概率选择，每个结构固定两次增强；validation 对每个结构各测六个 ID 条件。test 对每个结构各测上述 11 个条件。OOD/stress 不参与超参、早停或物理权重选择。

在 `voigt_ood` 和 `drop30_ood` 中，共享评分器仍采用名义 Gaussian/无掉峰模型，用于明确的模型失配实验；不能事后换成真实峰形或真实消失峰集合。`broad_ood` 在 calibrated 是已知新峰宽，在 blind 是未知新峰宽，两者的科学含义不同。

窄窗口不必然制造多峰后验。rutile 的 110 峰位置不依赖 c，但强度、其他峰尾部及先验仍可能携带信息；不能直接宣布 c 完全不可辨识。只有 `no_signal_stress` 按定义具有精确先验后验。

## 6. 数据规模、结构分组和正式发布

| preset | train 独立 θ | val 独立 θ | test 独立 θ | train/val/test 观测数量 |
| --- | --- | --- | --- | --- |
| smoke | 32 | 8 | 8 | 64 / 48 / 88 |
| pilot | 5000 | 512 | 512 | 10000 / 3072 / 5632 |
| main | 100000 | 10000 | 5000 | 200000 / 60000 / 55000 |

按**独立参数点**划分，再增强。同一结构所有噪声、mask 条件有相同 `group_ids`，绝不跨 train/val/test。θ 用 float64 保存，避免单参数任务因为标签 float32 量化引入大量完全重复点。随机分割主要测试先验内插值，不能当成参数空间外推。

学习曲线使用 train 的结构编号前 1k/5k/20k/100k 个，每个都保留两次固定增强；按结构前缀筛选，不是取文件前若干条。生成参数流不依赖 preset，前缀嵌套；正式曲线应从**同一个 main 发布**取子集，使 validation/test 与 dataset_id 完全一致。不要把 pilot 的 validation 成绩直接当 main 测试成绩比较。

布局：

```text
release/
  public/
    manifest.json              # 协议、先验、版本、文件哈希、dataset_id
    prototype.cif
    train/observations-*.npz
    train/targets-*.npz
    val/observations-*.npz
    val/targets-*.npz
    test/observations-*.npz     # 不含 theta、干净谱、真实隐变量
  private/
    manifest.json
    test/targets-*.npz          # 协调者评分使用
```

发布者生成一次，运行 `audit`，记录代码哈希、完整依赖锁文件和 `dataset_id`，然后给所有合作者同一份 `public/`。不要让各组独立安装最新版 pymatgen 再重新生成各自测试集。文件改变、代码改变或生成依赖改变都会影响发布指纹，评估器拒绝跨指纹预测。

该隔离用于研究流程防止误用，**不是安全沙箱或密码学盲测**：可复现种子和模拟器是公开的，自定义 Python 代码也可以访问文件系统。正式盲测须由协调者单独托管 private、限制测试访问，并审查推理代码；不得把 hash 校验描述成能防恶意作弊。

默认 shard=256，生成器不一次把整个训练集加载入内存。main 每任务每赛道 315k 条谱，counts+mask 未压缩约 6.45 GB；实际压缩大小与计数有关，需实测，不能承诺固定磁盘占用。大文件存 NAS。

## 7. 统一物理子集 `physics128`

全量 test 很适合摊销模型，但高精度积分/多起点搜索可能很慢。`--view physics128` 按结构 ID 的固定哈希选最多 128 个结构，保留它们全部条件。选择不依赖真值、方法输出或误差。同一结构集合用于所有条件。

主规模该视图共有 128×11=1408 张测试谱，validation 为 128×6=768 张。smoke 只有 8 个结构，所以该视图等于 smoke 全量。物理方法和神经方法都必须在该视图单独导出、打分；full 与 physics128 的数值不得直接作成对比较。`compare` 会核验视图与样本 ID。

共享物理候选选择默认每条件最多 128 个结构，也采用同一结构哈希。修改 `--physics-limit` 相当于更改评估子集，比较双方必须相同，并在结果中标明。不能只选“疑似多峰”或 ours 表现好的样本。

## 8. 模型可读输入与预测 ABI

`Adapter(context, checkpoint)` 初始化一次。`context` 包含原型 ID、track、参数顺序、先验上下界、2θ 轴、波长、dataset_id。

`predict(batch, n_samples, seeds)` 的 batch 只含：

| 字段 | 形状 | 语义 |
| --- | --- | --- |
| ids | `[B]` 字符串 | 原样回传、可作随机数键；不得用其重建测试真值 |
| counts | `[B,4096]` uint32 | 观测计数，缺测填零 |
| mask | `[B,4096]` bool | True=已观测 |
| exposure | `[B]` float | 已知 E |
| nuisance | `[B,5]` float | calibrated 为已知值；blind 全 NaN |
| nuisance_known | `[B]` bool | 是否已知 |

不传 θ、干净全谱、condition 名、group ID 或隐 nuisance。condition/group 保留在数据文件中供分组评分，标准 adapter 不接收它们。方法不得利用 condition 名选择知道 OOD 真相的专用规则。

三种输出，均为实际 Å 单位，**不是标准化参数或倒易长度**：

| kind | 必需输出 | 用途 |
| --- | --- | --- |
| point | `point: [B,d]` | 回归、MAP、选定的单点估计 |
| posterior | `samples: [B,256,d]` | 未经 oracle 排序、无权、近似 iid 的原始后验样本 |
| candidates | `candidates: [B,64,d]` 与 `point: [B,d]` | 重排/局部精修后候选；point 必须是实际候选之一 |

可选 `failed: bool[B]`。推理失败时采用事先声明的有限 fallback（例如先验均值）并标记 True，所有行仍参与计分；不允许删除困难样本。NaN/Inf、重复 ID、缺样本、多样本或错序均拒绝。超出先验的有限输出保留并计入越界率，不会偷偷裁剪；共享物理选择会排除先验外候选，若全部无效则使用先验均值 fallback 并计入失败率。

posterior 的统一点估计由评估器取**样本边缘中位数**，适配主 MAE；不会接受方法额外传入另一套点值来替换。点模型可用其预先声明的 mean/MAP/回归值，需在 `point_rule` 说明。边缘中位数不等于联合模态，也不保证物理合理，因此另报观察谱选出的候选。

`seeds[B]` 由推理 seed 和 sample ID 派生。随机方法必须使用这些种子，且先生成固定 256/64 个样本，再截取前 K；不允许看真值重排。建议保证改 batch size 不改变同一样本的随机候选。加权 SMC/MCMC 结果先按权重重采样，说明链混合与有效样本量；高自相关样本会影响 SBC/energy estimator，不能仅重复同一个点冒充后验。

GPU/NPU adapter 必须实现 `synchronize()`；NPU 用 `torch.npu.synchronize()`，CPU 为 no-op。调用前后同步后再计时；返回 NumPy 数组。不得把 test labels 用作 cVAE 的 posterior encoder 输入。

## 9. 两种接入方式

### 9.1 直接 adapter

内置 `xrdbench.api:PriorMean` 和 `PriorSampler` 可立即运行，用于校验管道。自己的方法实现同一接口：

```python
class Adapter:
    def __init__(self, context, checkpoint):
        self.context = context
        # 加载自己的已训练模型；核对参数顺序和训练数据版本。

    def synchronize(self):
        # NPU: torch.npu.synchronize(); CPU: pass
        pass

    def predict(self, batch, n_samples, seeds):
        # 所有标签与隐变量不在 batch 中。
        # 点模型返回 {"point": np.ndarray[B,d]}。
        # 后验模型返回 {"samples": np.ndarray[B,256,d]}。
        raise NotImplementedError
```

完整点模型接线代码见 `examples/torch_point_adapter.py`。其 `ExampleNet` 仅供接口示例，不能叫 DeepLPnet/AlphaDiffract。训练时保存：

```python
torch.save({
    "state_dict": model.state_dict(),
    "dataset_id": public_manifest["dataset_id"],
    "parameter_names": ["a", "c"],
}, checkpoint_path)
```

示例网络预测 `[0,1]` 参数，再由 adapter 转回 Å；模型输入含谱/mask 双通道与可观测元数据。已训练模型的具体网络和损失可自行替换。

```bash
export XRD_BENCH_DEVICE=npu:0
xrdbench run --public "$XRD_PUBLIC" \
  --adapter examples.torch_point_adapter:Adapter --checkpoint model.pt \
  --metadata method.json --kind point --split val --seed 0 \
  --output "$XRD_OUTPUT/val_seed0"
```

自定义 Python 包须在当前环境可导入。只有在授权的 Merlin Ascend910B2 容器内运行 NPU 推理；不能在 CPU 开发机上假定有 torch_npu。这里没有自动申请 GPU 的命令。

### 9.2 离线预测文件，兼容原仓库的独立环境

原 baseline 不方便安装同一 PyTorch/sbi 版本时，保留其环境，按发布顺序导出一个 NPZ，包含 `ids` 与对应预测数组，然后在 evaluator 环境执行：

```bash
python -m examples.export_npz --public "$XRD_PUBLIC" \
  --input original_environment_predictions.npz --metadata method.json \
  --kind posterior --split test --view full --output "$XRD_OUTPUT/submission"

xrdbench validate --public "$XRD_PUBLIC" --submission "$XRD_OUTPUT/submission"
```

文件不允许 object/pickle 数组。也可直接使用 `SubmissionWriter.add(ids, prediction)` 分批写出、`finish()` 完成。离线导出不自动获得可信推理计时；自行给出同步计时脚本、硬件、batch、采样与后处理成本，由协调者复测。

## 10. 不同 baseline 的迁移要点

| 方法 | 需要替换/保留的部分 | 导出类型 | 不应做的事 |
| --- | --- | --- | --- |
| DeepLPnet-style CNN | 保留其 1D 局部谱编码思路；输入改为本谱轴、mask 与共同元数据；输出 d 个长度，在本数据重训 | point | 将原 ICSD/CSD 模型成绩称为本任务复现结果 |
| AlphaDiffract/ConvNeXt | 使用 backbone、改 4096 点输入和 d 维回归头；已知原型不需要未知晶系/空间群分类头 | point；ensemble 若只表达模型间分歧须标明 | 照搬其自动 80/10/10 split 或原数据增强，重划共同测试集 |
| MDN | 同一 CNN encoder，4/8/16 分量全协方差 GMM；声明有界分布/变换方式 | posterior | 将未归一化截断或事后 clip 当作正确截断高斯 |
| NSF/NPE | 同一谱编码，训练条件密度；单轮 amortized NPE，所有 train θ 来自共同先验 | posterior | 用单观测多轮 SNPE 却不计额外模拟成本；把 `[S,B,d]` 当 `[B,S,d]` |
| vanilla cVAE | 与 ours 共享 encoder/decoder/latent capacity；只去掉 Physics 项 | posterior | 推理时用 q(z\|θ,x) 的真实 θ；用 ELBO 冒充 NSF exact NLL |
| CNN+Physics | 与 CNN 相同容量，加入同一 Physics 项/后处理 | point 或 candidates | 只给 ours 更强编码器、更多模拟或更多搜索次数 |
| Physics MAP | 同一似然/mask/先验与 nuisance 信息，多起点全局+局部搜索；报告容差、前向次数、失败 | point | 只跑粗网格/单起点就宣称经典方法弱 |
| 数值物理后验 | calibrated 可低维积分，blind 需对 nuisance 边缘化；验证所有模式与分辨率/链混合 | posterior | 用 profile likelihood 或优化点集合冒充后验 |

主实验应报告“在共同任务上的架构迁移/重新训练”。只有数据、配置、代码与原论文一致且真正复跑原实验时，才称“复现原论文成绩”。不得把本次无谱 controls 当作已完成的强 baseline。

### 已检查的上游实现参考

- [OpenAlphaDiffract README](https://github.com/AdvancedPhotonSource/OpenAlphaDiffract/blob/ec118b9d899f57e8971a7ad4d4aa23b3f38572e0/README.md) 与 [trainer.local.yaml](https://github.com/AdvancedPhotonSource/OpenAlphaDiffract/blob/ec118b9d899f57e8971a7ad4d4aa23b3f38572e0/configs/trainer.local.yaml)：参考其 manifest/训练/评估分离与 ConvNeXt 配置。原配置 `dim_in=8192`、`num_lp_outputs=6`、`auto_generate_manifests=true`，并有训练增强，迁移时必须替换这些设置。它的原实验与本协议波长/角度条件不同，不能只插值后套用公开权重。
- [sbi 的 SBC 实现](https://github.com/sbi-dev/sbi/blob/cef9ac3784ba29032a4008d574507dc390b24c3f/sbi/diagnostics/sbc.py)：参考 prior-predictive θ/x、posterior sample、逐参数 rank 的定义。该实现内部批量样本为 `[S,B,d]`，本工具要求 `[B,S,d]`。本项目独立实现 NumPy 指标，核心 evaluator 无 sbi/torch 依赖，不宣称数值与上游逐位一致。
- [DeepLPnet 官方仓库](https://github.com/src47/DeepLPnet) 与 [论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8662964/)：参考 CNN 给物理搜索初值的对照设计。本次新增代码没有复制其网络代码，仍需负责该 baseline 的合作者检查原架构与许可证并记录 upstream commit。

未把上游仓库代码混入本工具。采用上游代码时保留其许可证与作者声明；公开可下载不自动意味着可以任意重新授权。sbi 在 Ascend 上的具体 flow/采样路径还没有验证，不能仅凭通用 NPU smoke 通过就断言其所有算子兼容。

## 11. 训练、调参与消融预算

首轮统一预算建议作为本轮登记规则执行：pilot 最多 8 组超参，每组最多 1 NPU 小时，训练 seed=0；确定配置后 main 用 seeds=0/1/2，每 seed 最多 50000 次 optimizer update 或 4 NPU 小时，先到者停。都是单张 Ascend910B2、同一发布和训练结构预算。记录实际用量，不要求人为跑满；若发现某算法在此预算下明显未收敛，必须对所有方法统一修订预算并重新登记。

确定性方法用 validation 六个 ID 条件平均 normalized MAE 选 checkpoint；后验方法用 validation 平均 energy score 选 checkpoint，并同时报告 calibration/width。Physics 权重、采样策略、早停和优化容差只能看 train/val。数学上常数无谱 baseline 无训练预算；Physics 的网格构建、求解与额外模拟成本单独记录，不能假称免费。

共同 2×2 消融：CNN、CNN+Physics、cVAE、cVAE+Physics，共享谱 encoder 与数据。MDN/NSF 的主表也优先共享 encoder；另外列各论文原生强 backbone 的扩展结果，区分架构容量与概率建模贡献。

若 Physics 在测试时重排/精修，所有方法使用相同共享 scorer、候选预算、优化步数和停止容差，并分别报告前后成绩。本工具已实现统一**评分选择**，尚未实现统一局部精修；自行精修只能作为声明清楚的扩展，不能伪装成已完成公平消融。

对已条件于 x 的后验再乘一次 p(x\|θ) 不是自动正确的 Bayes 更新；这种启发式重加权/精修集合以 `candidates` 导出，不以 `posterior` 导出。若以后实现有严格推导的后验保持 MCMC，需要新增并验证相应协议，而非随意绕过当前检查。

额外模拟、额外在线增强、外部预训练都必须登记。v0.1 主表使用共同已发布的固定两次增强；更多在线增强属于单独 data-augmentation 实验，不能只为某方法打开。外部预训练另表，不与从零训练在同预算主表混排。

## 12. 计分定义与解读

主表按原型、track、条件分别报告，并给六个 ID 条件等权平均；三个 OOD 和两个 stress 单独报告，不参与“总体赢家”的一个混合平均。

| 指标 | 定义/单位 | 注意 |
| --- | --- | --- |
| MAE、RMSE | 每参数 Å | 参数顺序随 task manifest |
| absolute_relative_error | `abs(pred-truth)/truth` | 输出为比例，乘 100 才是百分比 |
| normalized_mae | 各参数 `abs(error)/(prior_upper-prior_lower)` 后平均 | 三个任务可理解的无量纲量，仍分别排名 |
| success_rel_0.005 | 所有参数最大相对误差 ≤0.5% | 另报 0.1%、1%；不是固定 Å 阈值 |
| p95_max_relative_error | 样本级最大相对误差的 95 分位 | 关注尾部失败 |
| energy_score | 在先验宽度归一化的 d 维空间：E‖X-y‖−½E‖X-X′‖ | 所有后验方法可比较；点模型不伪造分布参与此列 |
| coverage + interval_width | 各参数 50/80/90/95% 等尾区间 | 覆盖率与宽度必须一起读 |
| rectangle_coverage | 上述边缘区间的交集覆盖 | 不是同名 α 的联合 credible region，不宣称应等于 α |
| rank_histogram_10bins | 真值在 256 个样本中的逐参数 rank，随机处理完全相等 ties | ID 可作 marginal SBC 诊断；不输出不恰当的连续 KS p 值 |
| oracle_success@K | 前 K 个候选中，至少一个满足阈值 | 明确使用真值挑选，只能说明候选包含能力 |
| out_of_prior/failure_rate | 越界与显式失败频率 | 不静默裁剪，不删除失败行 |

Energy score 用 256 个样本的前半与后半做独立配对，O(S) 估计，避免全 pair 的 O(S²) 成本与含自配对 V-statistic 偏差。它是 MC 估计，单个样本上可能略为负数；不裁剪负值。proper score 的解释以近似 iid 后验样本为前提。

SBC 的数据必须来自协议先验与匹配的模拟分布。每个条件独立看 rank；重复条件共享 θ，不能把它们当独立 θ 增加有效样本量。OOD rank 可供观察，不能解释成“已证明真实后验校准”。均匀 rank 是必要诊断之一，不能证明模型一定使用了谱；因此必须与无谱 prior sampler、energy score、信息性条件下区间宽度联合比较。

### 观测谱选择的真实 top-1

```bash
xrdbench score --public "$XRD_PUBLIC" --private "$XRD_PRIVATE" \
  --submission "$XRD_SUBMISSION" --output "$XRD_SCORE" \
  --physics-k 8 --physics-limit 128
```

在 calibrated 上，评估器仅用 counts/mask/公开 nuisance 对前 K 个候选算 Poisson NLL，选出候选后才比较 θ 真值。K 可为 1/8/32/64；point 方法实际 K=1。选择结果写入 `physics_selected_metrics.npz`，与原始 posterior 指标分开，原后验样本不被修改。

pilot 建议 K=8，main 冻结为 K=64；不同 K 不合并排名。前向次数与该子集的 scorer wall time 单独记录。无信号时所有候选等似然，固定取第一个；其每观测 bin deviance 按代码约定记 0，不把它解读成“拟合得完美”。

### 不确定性与统计比较

`score` 为 normalized MAE 和 energy score 给出 2000 次**按独立结构分组**的 bootstrap CI，不以噪声/条件行作独立重复。主 ID 汇总在每个 θ 的六个条件上平均后再 bootstrap。

```bash
xrdbench compare --a scores/cvae_seed0 scores/cvae_seed1 scores/cvae_seed2 \
  --b scores/nsf_seed0 scores/nsf_seed1 scores/nsf_seed2 \
  --metric energy_score --condition id
```

先对各方法训练 seeds 求样本级平均，再按相同结构成对 bootstrap。差值是 A−B，误差/energy 越低越好；success 越高越好。输出各 seed 的均值，CI 只反映结构采样不确定性，不包含训练 seed 的总体随机效应。不得把三次 seed 的所有增强行当 3N 个独立材料。

## 13. 数值后验与可辨识性验收

工具提供 `reference-grid`，只读观测，不读标签：

```bash
xrdbench reference-grid --public "$XRD_PUBLIC" --sample-id "$XRD_SAMPLE_ID" \
  --points 65 --output "$XRD_OUTPUT/grid65"
```

使用均匀先验的等体积网格中心，输出归一化 log weights、均值、最大单格权重和有效网格数。无信号输入应回到均匀先验；这一点有自动测试。

**此命令是诊断工具，不是已认证的强物理 baseline。** 高计数下后验可能比网格间距窄很多。输出固定 `certified_reference=false`，限制最多 20000 网格点以防误启动巨量 CPU 运算。主参考需由物理负责人实现粗到细/自适应积分或其他可靠采样，检查：网格/容差加密后均值、50/90/95% 区间及各模态质量稳定；边界模式没有丢失；blind 的 nuisance 已边缘化而不是 profile。

建议 pilot 阶段预先固定 `physics128` 中若干样本作收敛检查；均值变化小于 0.1% 先验宽度、区间端点变化小于 0.5% 先验宽度、模态质量变化小于 0.01 作为起始验收阈值，并报告更细网格结果。若未达到，只能标为“未收敛参考”，不能用它判定哪个生成模型错误。网格 posterior 的 energy/coverage 同样须通过加密检查，不能只看均值稳定。

## 14. 计时、存储和硬件

本项目实验当前使用 Ascend910B2；CPU 环境负责模拟、评估和文件管理。执行者应遵守所在平台的资源授权，私有队列配置保存在未提交的部署文件中。

已做基础接口验证的组合为 Python 3.11.9、torch 2.7.1+cpu、torch_npu 2.7.1.post8、CANN 8.5.1。torch 的 `+cpu` 后缀不表示 NPU 计算回退 CPU。各方法的特殊算子仍需单独 smoke，特别是 flow distribution 与旧版 TensorFlow/PyG 代码。私有镜像地址不属于公开协议。

不要求把原 baseline 的旧依赖硬装入评分环境。推荐训练环境与 CPU evaluator 环境分开，通过 NPZ 交付。数据、权重及运行输出路径由 `XRD_DATA_ROOT`、`XRD_RUN_ROOT` 等本地环境变量指定，不将个人路径、SSH 登录信息和平台凭证写入公开仓库。

runner 记录模型加载、一次 warmup、逐 batch 同步后的模型时间、含读文件/hash/导出的 pipeline 时间。pipeline 不含加载、预热、最终提交自检和协调者评分。warmup 与加载单列，不能只报告省略它们的时间而声称“单谱冷启动”。预测缓冲到约 1024 行再写分片，以减少 NAS 小文件访问。物理评分/精修另外计入；本版没有自动合成一个全量统一后处理端到端延迟，比较时应明确相同 batch/K/view 和计时口径。

## 15. 协调者与合作者的交付顺序

1. 协调者确认协议版本与预算，统一生成 pilot；完成 audit 与无谱 controls，登记 dataset_id。
2. 每位合作者先接 smoke，跑 validate；再在 pilot train/val 调试自己的模型。
3. 物理负责人先完成 posterior 可辨识性和收敛检查，避免把单峰任务宣传为多峰恢复。
4. 冻结 main 配置、公共数据发布、physics128 和共享后处理设置。合作者提交训练与调参记录后才统一 test。
5. 每方法交付代码版本、依赖、完整 method.json、checkpoint 哈希、三 seed 预测 manifest/NPZ、同步计时脚本、失败/额外模拟记录。
6. 协调者用独立 evaluator 打分，核对指纹/视图/样本数，输出原始点、posterior、oracle 和 physics-selected 四类表；共享同一批结果做成对比较。

文档末尾提交核对表：

- [ ] 原型、参数顺序、Å 单位、track、dataset_id、view 都一致。
- [ ] 没有重划测试集，没有把 augmentation 跨 split，没有读取测试真值或隐 nuisance。
- [ ] 训练/早停/超参只看 train/val；外部预训练/额外模拟已登记。
- [ ] posterior 样本未按真值排序、未做未声明的局部精修/clip；K 是固定前缀。
- [ ] 失败有 fallback 和 failed 标记；不删行；validate 通过。
- [ ] 性能数字来自 main 或明确标为 pilot/smoke；物理方法与神经方法在相同 view 上比较。
- [ ] 保存 checkpoint、配置、原始预测、评分文件、版本与资源成本，能够复查。

## 16. 已实现与待补齐

已实现：三个原型；两个信息赛道；11 条件；分组数据/标签分离；固定物理子集；框架无关导出/校验；点误差、energy、边缘 coverage/width、SBC rank、oracle@K；calibrated 共享物理选择；按结构成对 bootstrap；CPU 端到端测试。
